# GEMINI.md

Project memory for Gemini (Gemini CLI, Gemini Code Assist) lives in
[`AGENTS.md`](./AGENTS.md). This file exists because Gemini CLI's
auto-loader looks for `GEMINI.md` at the repo root; it intentionally
has no content of its own so that all agent-facing project memory has
exactly one source of truth.

If you are reading this file, please open `AGENTS.md` and follow it.
