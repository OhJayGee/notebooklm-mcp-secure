# CODEX.md

Project memory for Codex (Codex CLI, GitHub Copilot Chat / Workspace
where they support repo-level instructions) lives in
[`AGENTS.md`](./AGENTS.md). This file exists because some Codex
auto-loaders look for `CODEX.md` at the repo root; it intentionally
has no content of its own so that all agent-facing project memory has
exactly one source of truth.

If you are reading this file, please open `AGENTS.md` and follow it.
